# PHPlus
PHPlus is a PHP toolkit currently in active development, built specifically for Windows. Linux support is not yet implemented and is not planned until after the first stable Windows release. The goal is to simplify PHP development with clean, simple commands — no ANSI hassle, minimal setup, just intuitive output, smart pauses, and file handling. 
The file supports Windows only.

# How to use

Replace PHPlus file in your directory, and edit your another files make this:

// Connect PHPlus functions

require 'PHPlus.php'; 

Done, very easy!
